# Security policy / Sicherheit

English · Deutsch (below)

## English

If you find a security issue in AgentWorkbench, please **do not open a public issue**. Open a private report instead: on GitHub go to the repository's **Security** tab and choose **Report a vulnerability** (private security advisory).

Please include what you found, how to reproduce it and which version or commit you used. I will answer as soon as I can and credit you if you like.

Supported: the latest commit on `main`. What the app protects and what it does not is described in [docs/security.md](docs/security.md).

## Deutsch

Wenn du eine Sicherheitslücke in AgentWorkbench findest, eröffne bitte **kein öffentliches Issue**. Melde sie stattdessen privat: Gehe auf GitHub im Repository auf den Reiter **Security** und wähle **Report a vulnerability** (private Security-Advisory).

Bitte nenne, was du gefunden hast, wie man es nachstellt und welche Version oder welchen Commit du nutzt. Ich antworte so bald wie möglich und nenne dich auf Wunsch als Entdecker.

Unterstützt wird der jeweils neueste Commit auf `main`. Was die App schützt und was nicht, steht in [docs/de/security.md](docs/de/security.md).
